================================================================================
                          ENDPOINTS DISPONIBLES
================================================================================

🔹 GET  /health                          → Verificar estado del servidor
🔹 GET  /api/fotos                       → Listar todas las fotos
🔹 GET  /fotos/{nombre}                  → Ver/descargar una foto
🔹 POST /api/upload                      → Subir una nueva foto
🔹 POST /api/fotos/delete                → Eliminar una foto

================================================================================
                          CÓMO USAR
================================================================================

1. INICIAR EL SERVIDOR LOCALMENTE:

   docker compose -f docker-compose.upload.yml up -d

2. VERIFICAR QUE FUNCIONA:

   curl http://localhost:3001/health

3. SUBIR UNA FOTO:

   curl -X POST http://localhost:3001/api/upload -F "photo=@mi-foto.jpg"

4. LISTAR FOTOS:

   curl http://localhost:3001/api/fotos

5. VER UNA FOTO:

   curl http://localhost:3001/fotos/1712345678901-abc123.jpg

6. ELIMINAR UNA FOTO:

   curl -X POST http://localhost:3001/api/fotos/delete \
     -H "Content-Type: application/json" \
     -d '{"fileName": "1712345678901-abc123.jpg", "password": "tigre2026"}'

================================================================================
                          CONFIGURACIÓN DE DOCKER
================================================================================

🐳 Contenedores creados:
   - eltigre-uploader       → Servidor Node.js en puerto 3001
   - eltigre-cloudflared-uploader → Túnel Cloudflare conectado a uploader:3000

📁 Volúmenes:
   - ./srv:/srv            → Persistencia de fotos en tu máquina host

🌐 Cloudflare Tunnel:
   - Se conecta automáticamente a http://uploader:3000
   - URL pública generada por Cloudflare
   - Token ya configurado en docker-compose.upload.yml

================================================================================
                          VARIABLES DE ENTORNO
================================================================================

UPLOAD_DIR=/srv           → Directorio donde se guardan las fotos
PORT=3001                → Puerto del servidor (mapeado a 3000 internamente)
ADMIN_PASSWORD=tigre2026 → Contraseña para eliminar fotos
NODE_ENV=production       → Modo de ejecución
